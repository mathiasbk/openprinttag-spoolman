{% elif step == 'mode' %}

Choose how the bridge runs

In a dry run the bridge reads everything and shows what it would do, but writes nothing to Spoolman. It remembers the consumption from the first poll, so when you turn dry run off, what was used in the meantime is deducted from linked spools too.

Off: the dashboard asks whether an unknown spool should be linked to an existing one or created, which avoids duplicates. On: the bridge creates the spool right away.

On: what the printer consumes is deducted from the linked spool. Off: the bridge only links spools and sets their location. Turn it off if something else, such as a print tracker, already deducts filament in Spoolman.
